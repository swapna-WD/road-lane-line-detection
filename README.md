# 🛣️ Road Lane Line Detection 🚗

This is a **Road Lane Line Detection** project that uses Computer Vision and Machine Learning techniques to identify and overlay lane lines on roads in images and videos. The system is designed to help in building intelligent transportation systems and can be used as a foundation for autonomous driving applications.

## 🔍 Project Overview

The goal of this project is to:

- Detect lane lines in road images and real-time video streams.
- Process frames using image filtering, edge detection, and region of interest selection.
- Apply convolutional neural networks (CNNs) for improved line detection in complex scenarios.
- Provide interactive feedback or visualization for the user.

- Gaussian Smoothing
